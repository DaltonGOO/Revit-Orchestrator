Connect LLMs to Autodesk Revit

Revit Orchestrator is an open-source MCP server and Revit add-in that lets AI assistants read and modify Revit models through a schema-validated, multi-adapter tool architecture — covering the Revit API, pyRevit scripts, Dynamo graphs, and composed workflows.

What it is

One bridge. Every Revit automation.

An AI-friendly interface to the work you already do in Revit.

AI

Talk to Revit

Claude or OpenAI calls registered tools through the Model Context Protocol. The LLM gets typed schemas, examples, and side-effect declarations — not a free pass to your model.

+

Extend in minutes

Drop a JSON file in tools/ and a hot-reload watcher registers it instantly. Wrap a C# command, a pyRevit script, or a Dynamo graph — same contract.

✓

Governed by schema

Every call is validated against JSON Schema, gated by permissions and preconditions, tracked with model-change deltas, and routed across the named-pipe IPC boundary on the right thread.

Architecture

Three processes, two boundaries, one tool catalog

The LLM speaks MCP to a Python server, which talks to a C# add-in over a named pipe.

Python MCP server

Registry & dispatch

Loads tool definitions from tools/*.json, validates calls against JSON Schema, runs preconditions, and routes to the right adapter.

Named pipe IPC

Length-prefixed JSON

Communication uses Windows Named Pipes with 4-byte LE length prefix and UTF-8 JSON. UUID correlation matches request to response.

C# add-in

ExternalEvent bridge

The pipe runs on a background thread; an ExternalEvent hops back to the Revit main thread to execute API calls inside transactions.

Adapters

Wrap the Revit automation you already have

A tool's adapter field decides how it runs — same contract, different runtime.

revit

C# Revit API

Direct access to the Revit API through a typed C# command class. Best for element creation, queries, and model edits inside a transaction.

pyrevit

pyRevit scripts

Reuse existing IronPython scripts. Arguments are passed as environment variables; stdout and stderr are returned to the caller.

dynamo

Dynamo graphs

Run a .dyn graph with parameterized inputs. Input node names become argument keys; outputs flow back to the orchestrator.

workflow

Composed flows

Declarative multi-step workflows with bindings between steps, guards, retries, and aggregated governance. Calls any other registered tool.

Tool definition

One JSON file, one new capability

The dispatcher reads tool definitions and exposes them as MCP tools. Description, parameter schema, permissions, side effects, preconditions, and examples all live alongside each other — which means the LLM, the UI, and the audit log all see the same contract.

  • Hot-reloaded by a filesystem watcher
  • Validated against JSON Schema before dispatch
  • Categorized with permissions, side effects, and preconditions
  • Documented in-place with runnable examples

Design pillars

Structure, stability, and scale

The shape of the codebase, in three words.

S

Structure

Every tool is a JSON contract; the dispatcher is a single entry point; adapters are interchangeable. The LLM, the UI, and workflows all consume the same registry.

S

Stability

JSON Schema validation, preconditions, and permission gates run before any Revit transaction. The named-pipe protocol uses UUID correlation and explicit timeouts so failures surface as structured errors, not crashes.

S

Scale

Hot-reloaded tool definitions, multi-version Revit support via conditional compilation, and a workflow engine for composing steps mean teams can grow the catalog without changing the core.

Get started

Up and running in a few commands

You'll need Python 3.11+, .NET 8 SDK, Revit 2025 or 2026, and a Claude or OpenAI API key.

1. Clone & install

# clone the repo
git clone https://github.com/DaltonGOO/Revit-Orchestrator.git
cd Revit-Orchestrator

# install the Python MCP server
cd src/mcp-server
pip install -e ".[dev]"

2. Build the Revit add-in

cd src/revit-addin
dotnet build -p:RevitVersion=2025 -c Release

3. Configure your LLM

# Claude
set ANTHROPIC_API_KEY=sk-ant-...

# or OpenAI
set OPENAI_API_KEY=sk-...
set ORCHESTRATOR_LLM_PROVIDER=openai

4. Start the server & launch Revit

cd src/mcp-server
python -m orchestrator.server

# Then open Revit and click the
# Orchestrator panel in the ribbon.
