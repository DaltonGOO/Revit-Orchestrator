What it does

Ask. Run. Done.

An AI sidekick that actually reaches into your model.

?

Ask in plain English

"How many walls are on level 2?" "Find all views not on a sheet." "Show me the project warnings." The assistant answers from your live model — no scripting, no menus.

✓

Audit & fix

Spot orphan rooms, missing fire ratings, hidden categories, and other QC issues in seconds. Then ask the assistant to fix them — it edits the model in a real, undo-able transaction.

+

Reuse what you have

Wrap an existing pyRevit script, Dynamo graph, or C# command in one small JSON file and the assistant can call it. No need to throw out the automation you've already built.

How it works

The AI talks to a translator that talks to Revit.

Three pieces, with the heavy lifting hidden behind the scenes.

The AI assistant doesn't touch Revit directly. It picks a tool from the Orchestrator's catalog, the Orchestrator validates the request, and the Revit add-in runs it on the main Revit thread inside a real transaction — so every change is undo-able and logged.

Sample tools

Three flavors. Same conversation.

Each kind of tool is just a folder of scripts in the repo. Drop yours in — the assistant sees it.

C#

Revit API scripts

Small .cs files using the Revit API directly. Best for fast, typed model edits and queries.

  • project_summary — levels, sheets, area, counts
  • warnings_summary — the bell-icon list, grouped
  • views_not_on_sheets — orphan view cleanup
  • create_sheets_from_views — bulk-make a sheet set

Python scripts

Get it

Install in two minutes.

No Python, no .NET SDK, no build tools. Download, unzip, run one script.

1

Download the latest release

Grab the zip from the releases page.

2

Unzip and run install.ps1

Right-click install.ps1 and choose Run with PowerShell. It copies everything into the right Revit folder.

3

Set your API key

Add ANTHROPIC_API_KEY (Claude), OPENAI_API_KEY (ChatGPT), or point at a local OpenAI-compatible server (Ollama, LM Studio, llama.cpp). The installer prints the exact command.

4

Open Revit

The Orchestrator panel appears in the ribbon. Click it, type a question, watch it work.
